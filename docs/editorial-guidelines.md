# แนวทางบรรณาธิการและภาษาเว็บไซต์ PMNapan Library

## วัตถุประสงค์
รักษาภาพลักษณ์เว็บไซต์ให้เป็นคลังข้อมูลธรรมะและผลงานของพระมหานภันต์ สนฺติภทฺโท ที่อ่านง่าย เชื่อถือได้ สุภาพ เป็นกลาง และใช้ภาษาไทยสอดคล้องกันทุกหน้า

## ภาษาที่ใช้บนเว็บไซต์
- ใช้ประโยคสั้น ชัดเจน และเป็นภาษาขององค์กรหรือคลังข้อมูล ไม่ใช้คำอธิบายกระบวนการทำงานของเครื่องมือ โปรแกรม หรือผู้จัดทำภายในในหน้าสาธารณะ
- หัวข้อหลักระบุประเภทเนื้อหาหรือประเด็นโดยตรง เช่น “ข่าวและบทสัมภาษณ์”, “วิดีโอเผยแพร่ล่าสุด”, “เหตุการณ์สำคัญและบทบาทของพระมหานภันต์”
- ข้อความประกอบบอกประโยชน์ในการใช้งาน ส่วนปุ่มใช้คำกริยาที่แสดงผลลัพธ์ เช่น “ดูวิดีโอ”, “อ่านข่าวต้นทาง”, “ล้างตัวกรอง”
- รักษาความสม่ำเสมอของคำว่า “คลังวิดีโอ”, “หมวดรายการ”, “คลิปที่บันทึกไว้”, “แหล่งเผยแพร่”, “ข้อมูลอ้างอิง” และ “ข่าวและผลงาน”
- ป้ายภาษาอังกฤษที่ใช้เป็นองค์ประกอบออกแบบควรสั้น มีความหมายตรงกับหัวข้อภาษาไทย ไม่ใช้ศัพท์ทางเทคนิคโดยไม่จำเป็น
- หน้าสถานะว่างและข้อความแจ้งข้อผิดพลาดระบุสิ่งที่เกิดขึ้นและทางเลือกถัดไป ไม่กล่าวถึงระบบภายใน

## หลักฐานและความถูกต้อง
- ชื่อวิดีโอ ชื่อผลงานและคำบรรยายโดยผู้เผยแพร่ คงตามต้นทาง เว้นแต่มีหลักฐานว่าข้อมูลต้นทางเปลี่ยนหรือสะกดผิดและได้รับอนุญาตให้แก้
- คำคมและคำพูดอ้างอิงของพระมหานภันต์ต้องอ้างอิงจากภาพ เสียง หรือข้อความต้นฉบับ ห้ามแต่งเพิ่มเติม
- บทสรุปข่าวและชื่อเหตุการณ์ในเส้นเวลาสามารถปรับสำนวนเชิงบรรณาธิการเพื่อความกระชับได้ แต่ห้ามเพิ่มหรือเปลี่ยนเหตุการณ์ บุคคล วันที่ จำนวน หรือที่มาโดยไม่มีหลักฐาน
- แยกวิดีโอจากช่องเผยแพร่โดยตรง คลิปข่าว และเอกสารอ้างอิงให้ชัดเจนโดยใช้ป้ายและลิงก์ต้นทาง ไม่อ้างว่าเป็นบันทึกไลฟ์ฉบับเต็มหากตรวจสอบไม่ได้
- หากข้อมูลยังไม่ครบ ให้ระบุสถานะอย่างกระชับในหมวดข้อมูลอ้างอิงและหน้าแหล่งข้อมูลโดยไม่กระจายคำชี้แจงซ้ำทุกการ์ด
- หน้าแหล่งข้อมูลรวบรวมคำอธิบายขอบเขตคลังและแนวทางอ้างอิงที่จำเป็น ข้อความความยินยอมและความเป็นส่วนตัวต้องคงไว้ตามความจริง


## Transcript และคำถอดเสียง
- รับเฉพาะคำถอดเสียงหรือคำบรรยายที่มีต้นฉบับตรวจสอบได้
- สถานะเริ่มต้นต้องเป็น draft และห้ามนำ draft ไปใช้ใน Public Search หรือแสดงเป็นคำถอดเสียงที่ตรวจสอบแล้ว
- การเลื่อนสถานะเป็น verified ต้องมีบันทึกการตรวจเทียบกับต้นฉบับ
- การนำเข้าไฟล์ใช้ `scripts/import_transcript.py`; หาก key เดิมมีข้อมูลอยู่แล้ว ต้องยืนยันการแทนที่ด้วย `--replace`
- เก็บ SHA-256 ของไฟล์ต้นทางเพื่อช่วยตรวจว่ามีการเปลี่ยนไฟล์หรือไม่
- ห้ามใช้การสรุป การคาดเดา หรือข้อความที่สร้างขึ้นใหม่แทนคำพูดในต้นฉบับ
- หากฟังไม่ชัดหรือหลักฐานไม่พอ ให้คงสถานะ draft จนกว่าจะตรวจสอบได้

## การออกแบบและตรวจรับ
- ใช้หัวข้อ h1 เพียงหนึ่งรายการต่อหน้า ตามด้วย h2/h3 อย่างเป็นลำดับ
- ตรวจตัวอักษรและแถบเมนูที่หน้าจอคอมพิวเตอร์ แท็บเล็ต และมือถือ ไม่บีบเมนูให้เล็กเกินกว่าจะอ่าน
- ทุกปุ่ม ลิงก์ และช่องค้นหาต้องมีชื่อที่สื่อความหมาย เข้าถึงด้วยแป้นพิมพ์ และมีสถานะที่เห็นได้ชัด
- รักษาภาพต้นฉบับของคอลเลกชัน 4 พส. ให้เหมือนต้นฉบับทุกไบต์ตามข้อกำหนดเดิม
- เมื่อแก้เนื้อหาคงที่ต้องอัปเดต scripts/build_multipage.py และไฟล์ HTML ที่สร้างจากสคริปต์ให้ตรงกันทุกหน้า
- ตรวจสอบข้อมูลหลัก: วิดีโอ 699 รายการ, หมวด 4 พส. 16 เหตุการณ์, 32 ข่าว/บทวิเคราะห์, 11 วิดีโอ/รายการ, 5 เหตุการณ์สำคัญของพระมหานภันต์ และ 6 รายการข้อมูลอ้างอิงเพิ่มเติม (ณ การตรวจครั้งนี้)
- รักษาระบบความยินยอม Analytics, ลิงก์จากต้นทาง, ปุ่มบันทึกคลิป, เมนูมือถือ และข้อมูลผู้จัดทำ YDML x IBHAP ในส่วนท้ายเว็บไซต์
