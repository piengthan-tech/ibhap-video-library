# รายงานตรวจลิงก์และภาพประกอบเว็บไซต์ PMNapan Library
วันที่ตรวจ: 18 พฤศจิกายน 2569

## ขอบเขต
- ตรวจ URL ในทะเบียนวิดีโอ 699 รายการ, ข่าว/บทสัมภาษณ์ 26 รายการ, สื่อภายนอก 26 รายการ, เส้นเวลา 4 พส. 16 เหตุการณ์ และข้อมูลแหล่งภาพคำคม
- URL ที่ไม่ซ้ำกันในทะเบียนทั้งหมด 789 รายการ รวม URL จาก HTML คงที่อีก 13 ลิงก์ (มีหนึ่ง URL ซ้ำ) ได้ 801 URL
- ใช้วิธี HTTP, YouTube oEmbed, TikTok oEmbed และเปิดหน้าเว็บจริงผ่านเบราว์เซอร์สำหรับผลที่ไม่ชัดเจน
- การตอบกลับ 403/400 จากเว็บไซต์ที่มีเงื่อนไขการเข้าชม ไม่ใช่หลักฐานว่าบทความหรือคลิปถูกลบ

## ผลและการแก้ไข
- URL ของข่าว MGR Online ที่ใช้โฮสต์ ai-content.mgronline.com มีปัญหาใบรับรอง SSL จึงเปลี่ยนเป็น URL บทความเดียวกันที่ https://mgronline.com/onlinesection/detail/9640000119906 และเพิ่มภาพข่าวต้นทาง
- URL ข่าว MGR Online ที่ใช้โฮสต์ social-mgr.mgronline.com มีปัญหาใบรับรอง SSL เช่นกัน จึงเปลี่ยนเป็น https://mgronline.com/live/detail/9690000057728
- ข่าว Dailynews 6 ลิงก์ตอบ HTTP 403 จากระบบป้องกันบอต แต่ยังปรากฏในดัชนีเว็บ และเปิดได้จนถึงหน้าตรวจสอบ Cloudflare จึงไม่ลบทันทีโดยไม่มีหลักฐานว่าบทความถูกถอดออก
- URL YouTube 336 รายการตอบสำเร็จผ่านการตรวจ oEmbed; เพียงลิงก์เพลย์ลิสต์ที่ส่งเข้าเครื่องมือตรวจในรูปแบบ watch URL ผิดประเภทนั้นตอบ 404 แต่เมื่อเปิดเพลย์ลิสต์โดยตรงในเบราว์เซอร์พบหน้าเพลย์ลิสต์ จึงเก็บไว้
- TikTok oEmbed 239 ลิงก์ตอบ 200, 132 ลิงก์ตอบ 403 และ 1 ลิงก์หมดเวลา; ตัวอย่างจากกลุ่มที่มีข้อผิดพลาดยังเปิดหน้าได้ในเบราว์เซอร์ จึงไม่ลบทั้งกลุ่มเพราะอาจเป็นข้อจำกัด API
- Facebook Reel หนึ่งรายการตอบ 400 ในการตรวจ HTTP แต่เปิดหน้าได้ผ่านเบราว์เซอร์
- ลิงก์ภายนอกที่เขียนคงที่ใน HTML อีก 13 ลิงก์ตอบ HTTP 200 ทั้งหมด
- ไม่พบรายการอื่นที่ยืนยันชัดเจนว่าเสียถาวรจากรอบการตรวจนี้ จึงรักษารายการที่ยังไม่สามารถพิสูจน์ว่าเสียไว้

## ภาพ Thumbnail
- หน้า “ปรากฏการณ์ 4 พส.” มีภาพประกอบสำหรับข่าวและบทวิเคราะห์ครบ 32 การ์ด: 26 แหล่งใช้ภาพบทความของตนเอง และ 6 รายการใช้ภาพเกี่ยวข้องจากข่าวอื่นในเหตุการณ์เดียวกัน โดยระบุเครดิตแหล่งภาพแยกต่างหาก
- หน้า “ข่าว บทสัมภาษณ์ และผลงาน” มีภาพครบ 26 การ์ด: ภาพจากบทความหรือผู้ดูแลจัดส่ง 23 รายการ, โลโก้ผู้เผยแพร่ 2 รายการ, ภาพบัญชีผู้เผยแพร่ 1 รายการ
- ตรวจการแสดงภาพบนคอมพิวเตอร์และมือถือแล้วไม่พบภาพเสียในการทดสอบ
- ภาพที่ดึงจากสำนักข่าวโดยตรงอาจเปลี่ยนได้ภายหลัง ระบบจึงใช้กราฟิกสำรองในกรณีโหลดภาพไม่สำเร็จ

## หลักเกณฑ์
- ก่อนลบข้อมูล ให้แยกความผิดพลาดชั่วคราวหรือการป้องกันบอต ออกจากการลบเนื้อหาจริง
- คง URL และเครดิตผู้เผยแพร่ให้ถูกต้อง
- ตรวจความพร้อมใช้งานของภาพและลิงก์เป็นระยะ
