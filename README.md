# คลังวิดีโอพระมหานภันต์ | Ven. Napan Video Library

เว็บไซต์สารบัญวิดีโอเพื่อการศึกษา เชื่อมผู้ชมไปยังคลิปสาธารณะจากช่องทาง YouTube และ Facebook ของผู้เผยแพร่ต้นฉบับ

- **119 รายการ** จาก 2 หมวดรายการ ณ การนำเข้าข้อมูลครั้งแรก
- ค้นหาคำสำคัญและชื่อเรื่องได้แบบทันที
- กรองตามหมวดรายการ ปีเผยแพร่ แพลตฟอร์ม และจัดลำดับ
- บันทึกรายการโปรดไว้ในเบราว์เซอร์ (localStorage; ไม่ต้องสร้างบัญชี)
- แชร์ลิงก์ตรงถึงหน้าแสดงรายละเอียดของแต่ละคลิป
- ใช้งานได้ทั้งคอมพิวเตอร์และโทรศัพท์

## ข้อมูลและความเป็นส่วนตัว

ไฟล์ `data/videos.json` เก็บเฉพาะข้อมูลวิดีโอสาธารณะที่จำเป็นต่อการค้นหา: ชื่อเรื่อง แพลตฟอร์ม ลิงก์ วันที่เผยแพร่ ความยาว และคำอธิบายจากผู้เผยแพร่ ไม่มีไฟล์วิดีโอจริง พาธ SSD ชื่อไฟล์ภายในเครื่อง ข้อมูลล็อกอิน หรือข้อมูลจากหน้า Notion ส่วนตัว

**เว็บไซต์นี้เป็นสารบัญอ้างอิง ไม่ใช่ช่องเผยแพร่อย่างเป็นทางการ และไม่ได้โฮสต์วิดีโอ**

## การอัปเดต

สารบัญเป็น static snapshot: เมื่อมีวิดีโอใหม่ใน Notion ต้องนำข้อมูลมาตรวจรหัสซ้ำและอัปเดต `data/videos.json` แล้ว commit/push เพื่ออัปเดตเว็บไซต์ ไม่ได้ซิงก์ Notion อัตโนมัติ

ใช้ `platform:video_id` เป็นรหัสรายการหลัก เพื่อไม่สร้างรายการซ้ำด้วยลิงก์เดิม (คลิปรีรันคนละลิงก์ยังต้องตรวจเนื้อหาด้วยมนุษย์)

ไฟล์สร้างชุดข้อมูลต้นทางถูกเก็บไว้บน SSD ของผู้จัดทำโดยไม่อัปโหลดไปที่สาธารณะ
