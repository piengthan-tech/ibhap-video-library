# PMNapan Library Dhamma Archive

เว็บไซต์สาธารณะสำหรับค้นหารายการวิดีโอของพระมหานภันต์ สนฺติภทฺโท รวมถึงรายการที่มูลนิธิ สกพ. จัดทำงานซับไตเติล (แยกประเภทและอธิบายความเกี่ยวข้องชัดเจน) ใช้ภาพปกวิดีโอจากผู้เผยแพร่ต้นทาง หรือภาพนิ่งจากต้นฉบับที่ตรวจสอบแล้ว ไม่สร้างภาพปกหรือคำพูดใหม่

### หลักเกณฑ์ความถูกต้อง

- คลังเก่าเดิม 112 ลิงก์ยังอยู่ครบ โดยหมวด “อาสาหาธรรม” 30 คลิปใช้ภาพนิ่งจากวิดีโอจริง มีทะเบียนเวลาจับภาพใน data/thumbnail-provenance.json
- เพิ่มลิงก์ใหม่ 179 รายการ; ใช้รหัส YouTube เป็นกุญแจป้องกันซ้ำ ชื่อเรื่องมาจาก metadata ของวิดีโอหรือทะเบียนลิงก์ของช่องต้นทาง
- งานต่างประเทศ/สื่อสากล 16 คลิปจากองค์กรผู้ผลิตและช่อง PM Napan เช่น Peacemakers Network, WildAid, She Talks Peace, WCC, PaRD และการเยือนเนปาล; ไม่อ้างว่าท่านเป็นผู้บรรยายตลอดทุกคลิป
- “คุยธรรมะสารพัน” จากทะเบียน URL ที่จัดไว้แล้วบน SSD จำนวน 102 ลิงก์; 101 ลิงก์ที่ตรวจสอบได้เพิ่มเข้าฐานข้อมูล 1 ลิงก์ยังเปิดตรวจสอบไม่ได้จึงไม่เผยแพร่ใหม่
- “หลวงพี่ช่วยด้วย” เป็นรายการ Workpoint ดำเนินรายการโดยพระมหาสมปอง ตาลปุตฺโต และมูลนิธิ สกพ. จัดทำซับไตเติล ไม่ถือว่าเป็นงานบรรยายของพระมหานภันต์
- เพลย์ลิสต์ซับของมูลนิธิระบุ 50 ลิงก์ แต่มีชื่อเรื่อง/ข้อมูลตรวจสอบได้ 34 รายการ; ใน 34 รายการนั้น 5 รายการถูกบล็อก จึงเผยแพร่เพียง 29 รายการที่เข้าถึงต้นทางได้
- คลิปที่ยังตรวจข้อมูลไม่ได้ ไม่ถูกใส่หัวข้อหรือวันที่ขึ้นเอง รวมถึงคลิปภายนอกที่ค้นเจอจากชื่อตรงกันอย่างเดียว
- วันที่เผยแพร่จาก YouTube ไม่ใช่วันที่จัดกิจกรรมเสมอไป; ไม่พบวันเผยแพร่ให้เว้นว่าง
- **ไม่ได้ดาวน์โหลด** รายการ “คุยธรรมะสารพัน” หรือ “หลวงพี่ช่วยด้วย” ซ้ำ

## Thumbnail ภาพข่าวและบทความ — 16 พฤศจิกายน 2569

- ตามคำขอผู้ดูแลเว็บไซต์ ได้นำบทความ TNews (N026) ออกจากหมวดข่าวแล้วเมื่อ 16 พฤศจิกายน 2569 เหลือ 26 ข่าว/บทความ และมีภาพประกอบ 21 รายการ (ไม่ลบข่าวอื่นที่เกี่ยวข้องกับเหตุการณ์เดียวกัน)


- หน้า \`press.html\` ใช้ภาพต้นฉบับจากเว็บไซต์ผู้เผยแพร่โดยตรงสำหรับ 23 ใน 26 ข่าว/บทความ (21 ภาพจากแหล่งเผยแพร่ และ 2 ภาพที่ผู้ดูแลเว็บไซต์ส่งมา) และแสดงการ์ดแบบไม่มีรูปถ้าไม่มีภาพที่ตรวจสอบได้
- ใช้รูปภาพที่อยู่ในบทความจริง หรือ metadata \`og:image\` ของบทความนั้นเท่านั้น ไม่สร้างภาพใหม่ ไม่ใช้โลโก้ทั่วไปแทน Thumbnail และยกเว้นภาพ 2 ภาพที่ผู้ดูแลเว็บไซต์อัปโหลดให้ใช้กับข่าวเดลินิวส์ ซึ่งจัดเก็บไว้ในโฮสต์เอง
- ที่มาของภาพอยู่ในแต่ละระเบียน \`data/press.json\` (thumbnail, thumbnail_source, thumbnail_checked_at, thumbnail_fit)
- ระบบใช้ lazy loading, สัดส่วน 16:9, contain สำหรับโปสเตอร์และกราฟิกที่มีข้อความ และซ่อนเฉพาะรูปที่โหลดผิดพลาดโดยไม่ซ่อนข่าวนั้น
- แหล่งข่าวเดลินิวส์บางหน้าไม่เปิดให้ระบบตรวจสอบรูปต้นฉบับ และไม่ใช้รูปจากสำนักข่าวอื่นแทน
- ภาพจากเว็บไซต์ต้นฉบับอาจเปลี่ยนแปลงหรือถูกปิด hotlink ภายหลัง จึงมี fallback ที่ไม่แสดงภาพเมื่อเปิดไม่ได้

## หมวดข่าว บทสัมภาษณ์ และผลงาน — 16 พฤศจิกายน 2569

- เพิ่มหน้า `press.html` แยกจากคลังวิดีโอและคำคม พร้อมเมนู “ข่าวและผลงาน” และแสดงรายการต้นทางจาก `data/press.json`.
- ค้นพบแหล่งอ้างอิงผ่านผลค้นหา Webmii แต่ไม่ได้คัดลอกเนื้อหาจาก Webmii หรือถือว่า Webmii เป็นแหล่งข่าวหลัก.
- เริ่มจากต้นฉบับที่อ่านและตรวจแล้ว 4 รายการ: Hands On Education Consultants (บทสัมภาษณ์), GotoKnow (บันทึกโครงการ), GotoKnow (โปรไฟล์) และสถาบันพัฒนาพระวิทยากร (ประวัติหน่วยงาน).
- ข้อมูลทุกระเบียนเก็บชื่อเรื่อง แหล่งเผยแพร่ ประเภท สรุปใหม่แบบสั้น ความเกี่ยวข้องกับพระอาจารย์ วันที่เผยแพร่เมื่อยืนยันได้ และ URL ต้นฉบับ; รายการไม่มีวันที่ต้องเว้นว่าง.
- หน้าเว็บไม่คัดลอกบทความทั้งหมด ไม่คัดลอกรูปภายนอก และไม่นำข้อมูลการติดต่อส่วนตัวจากโปรไฟล์มาแสดง.
- บันทึกโครงการเก่าต้องติดป้าย “โครงการย้อนหลัง” ไม่ปรับให้ดูเป็นกิจกรรมที่ยังเปิดรับสมัคร.
- ตรวจ URL ที่ซ้ำกันก่อนเผยแพร่ และตรวจบทบาทของพระอาจารย์แยกจากผลงานขององค์กร.
- ระบบค้นหาและกรองประเภทใช้ JavaScript จาก `assets/site.js`, รูปแบบ responsive อยู่ใน `assets/site.css`.
- สคริปต์สร้างหน้า `scripts/build_multipage.py` มีเมนูและหมวดใหม่นี้ เพื่อไม่ให้ถูกลบเมื่อสร้างหน้าเว็บใหม่.
