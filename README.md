# NAPAN Video Library

เว็บไซต์สารบัญวิดีโอเพื่อการศึกษา เชื่อมผู้ชมไปยังคลิปสาธารณะจากผู้เผยแพร่ต้นฉบับ

## สถานะข้อมูล (16 พฤศจิกายน 2569)

- แหล่งข้อมูลทั้งหมด 119 รายการ จัดเก็บทะเบียนต้นฉบับไว้บน SSD
- เผยแพร่บนเว็บไซต์ 112 คลิป: มามองพุทธ มุมมองพระ 82 คลิป และอาสาหาธรรม 30 คลิป
- อีก 6 คลิปพักรอตรวจสอบเนื้อหา และลิงก์ YouTube 2H-julZpBo0 ถูกคัดออก เนื่องจากคำบรรยายจริงเป็นรายการสื่ออาสาเพื่อคนพิการ แม้ชื่อและคำอธิบายคลิปจะระบุว่าอาสาหาธรรม
- 82 คลิปคัดกรองด้วยช่องผู้เผยแพร่ของพระอาจารย์หรือมูลนิธิ; 30 คลิปมีหลักฐานชื่อพระอาจารย์ในบทสนทนาจากคำบรรยายอัตโนมัติ
- การตรวจคำบรรยายไม่เท่ากับการยืนยันด้วยการรับชมทุกวินาที คำบรรยายอาจผิดพลาด ต้องตรวจเพิ่มเติมเมื่อมีข้อสงสัย

## การใช้งาน

ค้นด้วยชื่อเรื่อง คำสำคัญ ปีเผยแพร่ และหมวดรายการ บันทึกคลิปโปรดไว้ในเบราว์เซอร์ เปิดและแชร์คลิปต้นทางบน YouTube ได้ เว็บไซต์รองรับโทรศัพท์และคอมพิวเตอร์โดยใช้ฟอนต์ Prompt แบบไม่มีหัว สไตล์เว็บไซต์องค์กรสากล

## ความเป็นส่วนตัว

ไฟล์ data/videos.json มีเฉพาะ metadata ที่นำมาเผยแพร่ ไม่รวมไฟล์ MP4 ชื่อไฟล์ส่วนตัว พาธ SSD อีเมลหรือข้อมูลล็อกอิน

## การอัปเดต

เว็บไซต์เป็น static snapshot ไม่ได้ซิงก์ Notion อัตโนมัติ การเพิ่มวิดีโอใหม่ต้องตรวจแหล่งเผยแพร่และหลักฐานเนื้อหา เทียบ platform+video_id กับฐานเดิม แล้วสร้าง JSON สาธารณะก่อน commit และ push

ไฟล์ต้นฉบับและหลักฐานตรวจสอบเชิงลึกอยู่บน SSD ไม่ได้ถูกนำขึ้นพื้นที่สาธารณะ


## รูปภาพและข้อความที่แสดงบนเว็บไซต์ (16 พฤศจิกายน 2569)

- ชื่อเว็บไซต์ตามที่กำหนด: `PMNapan Linrary Dhamma Archive`
- มาสคอตมาจากภาพต้นฉบับที่ผู้ใช้กำหนด ลบพื้นหลังและย่อภาพเพื่อแสดงในเว็บไซต์
- ภาพตัวอย่างของคลิปอาสาหาธรรม 30 รายการ เป็น **ภาพนิ่งที่ถอดจากไฟล์วิดีโอต้นฉบับรายการเดียวกันจริง** ไม่ใช่ภาพที่สร้างขึ้นมาใหม่ ไฟล์แสดงอยู่ใต้ `assets/episode-stills/`
- เก็บ `data/thumbnail-provenance.json` อ้างอิง YouTube URL, video ID และเวลาที่จับภาพของคลิปแต่ละรายการ
- คลิปมามองพุทธ มุมมองพระ แสดงภาพปกจาก YouTube ของ video ID ที่ลงทะเบียนไว้
- ชื่อคลิปมาจากข้อมูลผู้เผยแพร่ ไม่มีการเขียนชื่อคลิป คำสอน วันออกอากาศ หัวข้อ หรือยอดจำนวนขึ้นใหม่
- รายการหน้าแรกของหมวด “เนื้อหาแนะนำ” สร้างจากหมวดที่มีอยู่จริงใน JSON เมื่อมีหมวดใหม่จะเพิ่มโดยอัตโนมัติ
- โปรดตรวจสอบแหล่งและเนื้อหาของคลิปใหม่ก่อนเผยแพร่; รายการ 7 คลิปที่ยังไม่ผ่านเกณฑ์ยังคงไม่แสดงต่อสาธารณะ
